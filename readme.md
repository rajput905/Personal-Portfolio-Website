# Personal Portfolio

## Files
- index.html: page content. Edit names, bio, education, skills, and projects here.
- style.css: colors (see :root at the top), fonts, and layout.
- script.js: contact form validation.
- assets/photo.jpg: add your photo here (about 800 x 1000 px works well).

## Run locally
Open index.html in a browser.

## Host on GitHub Pages
1. Create a repo named <your-username>.github.io (or any name).
2. Upload these files to the repo root.
3. Go to Settings > Pages, choose the main branch and / (root), and save.
4. Your site will be live at https://<your-username>.github.io

## Host on Netlify
Go to app.netlify.com, drag the portfolio folder onto the page, and you get a live link immediately.
